# Benchmark suites

Each `.rs` file is compiled as a separate library crate by `scripts/run_benchmarks.sh SUITE`.

| Suite | Source | Files | Licence |
|---|---|---|---|
| `aeneas` | `tests/src` of [AeneasVerif/aeneas](https://github.com/AeneasVerif/aeneas), commit `d119a474f852781f8ae88a85424f2f8ba8407b82`; the crates `avl`, `bst`, `tutorial` flattened to one file | 113 | Apache-2.0 |
| `humaneval_x` | Rust part of HumanEval-X ([THUDM/CodeGeeX](https://github.com/THUDM/CodeGeeX), `codegeex/benchmark/humaneval-x/rust/data/humaneval_rust.jsonl.gz`): declaration + canonical solution of each problem, generated by `scripts/import_humaneval_x.py` (the `use` lines of the external crates `rand`, `regex`, `md5` are removed) | 164 | Apache-2.0 |

Files that rustc itself rejects are reported as `rustc-rejected`: the negative
borrow-checking tests of Aeneas (`borrow_check_negative`, `loops_borrow_check_negative`,
`rust_borrow_check_issues`) and the two HumanEval-X problems that need the crates
`regex` and `md5`.
